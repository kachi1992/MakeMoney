# 07 · 安全、数据许可与发布门禁

本章是工程风险清单，不是法律意见。公开发布前需由了解经营主体和目标市场的合格专业人士评估；内部模拟测试与公众收费证券建议不可视为同一情形。来源见文档 11。

## 1. 发布范围

首版为公开材料研究和模拟投资实验，不收真实资金、不连券商、不实盘自动下单。新增的每日买卖建议是真实功能，不能用“教育”“模拟”“仅供参考”字样假定免于所有金融监管。美国投资顾问定义涉及业务、报酬及证券建议/分析等要素；本项目是否适用及有无排除项需要具体评估，不在本设计中作结论。[S12]

发布前填写：经营主体/所在地、目标用户和 storefront、免费/付费及广告模式、是否按用户情况个性化、是否公开排名/绩效、是否有关联方利益。不能依据开发者人在日本推断只适用日本规则。

默认内部/受限试点先行；对公众开启 advice_public 功能必须有记录的合规批准。功能旗标不是审核隐藏开关，提交 App Review 的版本和说明必须完整披露实际功能。Apple 对金融服务类 App 的主体/许可及第三方内容权利有相应要求；具体本 App 分类和审核不能预先保证。[S08]

## 2. 数据权利矩阵

每个 provider/dataset 必须确认：原始获取、缓存期限、公众展示、再分发、引用归属、原文链接、全文摘录、机器抽取、embedding、推理输入、训练/微调、衍生评分/建议、历史回测、导出、地域和并发用户。

个人 API 订阅、免费额度、公开网页和服务器端代理不自动解决上述权利。FMP 条款涉及授权用途、数据/衍生内容和终止后处理，必须依实际合同建白名单。[S04] 行情是否实时、延迟或日线按采购合同标记，不把延迟价写成实时。

许可对象持有 expires_at、allowed_uses、retention、attribution_rules、contract_ref；合同正文不提交仓库。权利检查在采集、模型调用、API 展示、下载/导出都执行。过期时暂停受限内容，清理需清理的缓存/数据，保留依法且合同允许的最小审计元数据。

历史不可变审计与源数据删除可能冲突：提前获取足够留存/复现权；未获权时不承诺永久可重放，删除受限正文但保留允许的 hash/撤权说明，并标记历史报告不可完整验证。不得以策略追踪为由违反删除要求。

## 3. 隐私与账户

最小化收集：身份登录标识、自选、模拟账本、偏好、通知 token、用户提交问题。首版不收真实券商账号、真实资产或身份证。分别公示目的、保留期、第三方、跨境处理与删除渠道。

向第三方 AI 发送个人数据前明确说明范围并取得显式同意；公开公司材料的共享分析不附带无关用户标识。拒绝同意不阻断普通浏览。[S08] App 内提供删除账户入口、再认证、进度；法律允许/要求保留的数据说明原因和期限。删除账户与管理 Apple 订阅分别告知。[S09]

建议初始操作策略：问答正文默认30天、运营日志30天、临时导出24小时过期；均需结合合同/隐私评估确认后生效。模拟历史保留至用户主动删除或公示到期；系统盘研究账本另有合法保留策略，不能与个人删除混淆。

## 4. 威胁与控制

| 威胁 | 控制/验证 |
|---|---|
| API key 泄漏 | 仅服务端 secret manager，环境分离，轮换，日志脱敏 |
| 越权查看模拟账户 | owner scope+对象授权，IDOR 测试，短时签名下载 |
| 财报内提示注入 | 不可信输入、只读工具、指令隔离、数值/引用验证 |
| SSRF/恶意文件 | 域名/IP检查、禁止内网目的地、解析沙箱、大小/解压限制 |
| 重放或并发下单 | 幂等键、事务锁、唯一 fill 键、单账本真值 |
| 策略被暗改 | 版本 hash、审批、未来生效、审计、用户可查 |
| 数据投毒/冲突 | 原始材料核验、供应商对比、隔离和撤回流程 |
| 过度访问/成本攻击 | 用户/租户/供应商配额，限长限token，预算熔断 |
| 备份泄漏 | 加密、最小权限、删除/恢复演练 |

禁用实盘 endpoint，不存 live brokerage credentials；未来实盘为独立设计和合规项目，不通过改一处 base URL 进入本次范围。

## 5. 绩效和建议披露

展示历史回测、前瞻模拟、用户手动实验的区别；包含起止、样本量、费用/滑点/股息/执行模型、基准、失败/不可执行数量与回撤。不能只挑盈利案例、用短期年化夸大、把分数当概率、以高胜率承诺收益。

FINRA 2214 对相关会员的投资分析工具要求披露方法、限制和假设，可作为工程披露参考，但不代表本项目当然受该条款直接约束或依其免责。[S07] 任何市场推广材料均需独立复核。

## 6. 上架与发布检查

检查实际可用登录/演示、隐私政策、账户删除、付费恢复、通知拒绝后流程、第三方 AI 同意、数据来源权利、模拟标识、风险披露、目标市场和年龄分级。订阅优先采用 StoreKit 路线；外链和支付例外按上架时 storefront 规则核查，不在此假定全球一致。[S08][S11]

发布门禁：工程 QA通过；数据许可签署并建白名单；证券建议业务评估完成；隐私与 AI 处理审查；App Store 材料完成；客服/纠错/故障响应可用。任一未满足不得标 public ready。所有这些均为待完成工作，不声称本次写文档即已通过。
