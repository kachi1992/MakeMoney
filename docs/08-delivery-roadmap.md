# 08 · 开发路线图与交付基线

按依赖推进，不以天数承诺完成。每个阶段必须有可执行成果、实际测试记录、未完成项和审查；没有凭证或商业许可的部分用合成数据实现相同接口，不伪称已接通。

## 1. 阶段划分

| 阶段 | 工作包 | 交付物 | 退出条件 |
|---|---|---|---|
| P0 基础与许可 | 锁定iOS/后端工具链、CI、环境、许可矩阵、30家试点选择规则、模拟演示 | 可启动工程、迁移、配置模板、合同扩展计划 | 合成数据读通；不含密钥；版本锁定；未获权功能受控 |
| P1 数据可信 | issuer/security/CIK、SEC增量、财务标准化、价格/行动、PIT版本 | 原始数据→特征流水线、质量报告 | 金标期间/金额零错；重述不泄漏；失败/缺失可见 |
| P2 研究与iOS阅读 | 今日/公司/财务/事件/证据、自选、AI提取与对比 | 完整阅读闭环、鉴权/缓存/离线 | 来源可追溯；注入/越权通过；缺数据能拒答 |
| P3 建议与模拟账本 | Rules-v1、冻结建议、组合风控、下一开盘模型、三种盘 | 每日建议→订单→fill→NAV、iOS建议与模拟盘 | 相同输入可重放；无透支/重复成交/未来信息 |
| P4 评价与实验 | 1/5/20/60日标签、买卖分评、基准/回撤、走样本外、审批 | 策略实验台、复盘页、失败试验留痕 | 独立金标和时间边界测试；未成熟不计胜负 |
| P5 产品化与受限试点 | 通知、账户删除/导出、可选订阅、运营/恢复/限额 | TestFlight包、运营手册、端到端报告 | 受限试点权限明确；隐私/许可/恢复测试完成 |
| P6 前瞻验证与扩展 | 固定策略真实时间运行、候选shadow、覆盖100及更多 | 带样本量的前瞻报告、升级审批、扩容评估 | 样本真实成熟；结论不过度宣传；公众发布另过门禁 |

P3 完成仅代表模拟交易闭环，不代表策略有效；P4标签算法通过不代表已有20/60日真实结果；P6不能靠历史数据回填伪装完成前瞻观察。

## 2. 建议并行工作线

数据/后端：P0→P1→P3账本→P4评估；iOS：P0合成接口→P2阅读→P3模拟→P5产品化；AI：P1金标准备→P2证据工作流→P4解释/漂移；QA/运营每阶段同步，不能最后才查时间泄漏。

依赖边界：P2可先合成数据搭UI；P3真前瞻必须依赖可靠PIT和行情/行动；P4历史回测须有历史成员与数据可用性说明；任何阶段真实公众展示都依赖相应数据权利。

## 4. 代码目录目标

`ios/` 客户端；`backend/` API/worker/domain；`tests/` 单元/契约/集成/金标；`infra/` 部署与备份；`contracts/` 版本契约；`examples/` 合成数据；`docs/` 设计与决策。未开始的工程目录不靠空文件充数。

## 5. Definition of Done

需求编号可追踪；实现/迁移/文档一致；测试实际运行有结果；无高危缺陷；权限/许可正确；失败/离线/缺数状态覆盖；监控和回滚明确。用户侧展示的收益必须来自可重放账本，不能截图伪造。

一个可演示的首版应包含：新材料→财务变化→带证据建议→模拟成交→余额/NAV→历史建议按窗口复盘。不能只交付聊天窗口或新闻列表就称完整MVP。
