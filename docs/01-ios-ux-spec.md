# 01 · iOS 信息架构与页面交互

关联 FR-001—019。首版 iPhone 优先，中文界面，保留英文公司名、财报术语与原文；深浅色、动态字体、VoiceOver 均纳入验收。本文为交互规格，不是已完成视觉稿。

## 1. 顶层导航

五个 Tab：**今日 / 研究 / 建议 / 模拟盘 / 我的**。自选在研究页顶部；策略实验与准确度在建议页和模拟盘内，不额外占 Tab。自然语言输入是研究入口之一，不取代可比较的数据表和历史记录。深链统一包含资源 ID 与版本，而非只含 ticker。

全局顶部可显示服务/数据延迟条。所有行情含价格时间与实时/延迟/EOD 标记；财报显示财年/期间，不混入公历季度。模拟资金标记在所有涉及订单、仓位和收益的页面保持可见。

## 3. 今日与研究

今日首页首屏显示“截至本地时间 X / 美东会话 Y”，随后是最多三项重要变化和全量入口，不用无限紧急红点催促交易。重要性按事件材料与预设规则解释，不能把点击率当投资价值。

卡片字段：公司、事件类型、事件发生/披露时间、新旧指标差、主要来源、分析状态。财报刚入库但未完成验证时显示“正在核验”，可以先读原文，不能显示未经校验的完整建议。没有重大变化时明确“本次更新未发现符合条件的新事件”。

公司财务页面默认最近 8 个已披露季度，支持年度与数值表；选择 GAAP/非 GAAP 时保持对照数据同口径。缺值用短横线加原因，图上留缺口，不连成零。收入使用货币金额，利润率使用百分比，变动使用百分点或 bp；点开图显示完整精度和来源。

## 4. 建议页线框

```text
每日建议     2026-10-02（会话日期，仅布局示意）
实验策略 Rules-v1 · 信息截至 … · 执行会话 …
数据完整 24 / 30 · 6 家暂不判断

[买入/增持] [持有] [减持/卖出] [观望]
虚构公司 DEMO.A        买入（模拟）
排序分 78.0 / 100      数据覆盖 85%
主要贡献：增长改善；风险：现金流偏弱
目标 0% → 9.5%        主评价窗口 20 交易日
[依据与反证]           [模拟计划]

排序分不是上涨概率。今日建议可能不产生订单。
```

线框数字仅合成示意，不是策略已跑出的结果。分数和风险使用文本/图标/符号，不只靠红绿辨认。未校准概率不出现圆环胜率等误导 UI。

建议详情分四层：结论摘要；事实与指标贡献；支持和相反证据；模拟执行及历史评价。重要风险不折叠隐藏。公开信号与基于个人模拟持仓产生的动作分栏显示，避免无持仓用户误以为要卖空。

历史建议默认展示**当时版本**，顶部可切“后来更正”；后者必须有明显标签。不可用今天的解释替换过去理由。动作后来被取消也保留。

## 5. 模拟盘线框

```text
模拟盘    [系统标准盘] [我的实验]
模拟资金 · 非真实交易
NAV $…  净收益 …  基准 …  最大回撤 …
数据截至 …  执行模型 NextSessionOpen-v1
[收益曲线] [持仓] [订单] [复盘]

待执行：2 笔，计划下一有效会话开盘
未成交/数据异常：1 笔，原因可查
```

系统盘不出现改资金、删除交易或手动买卖按钮。我的盘开启自动模拟前展示初始资金、固定策略、成本假设和执行时间；默认关闭自动执行，用户确认后打开。开关说明“仅模拟订单，不连接券商”。

手动盘订单表单只支持当前执行模型：证券、买/卖、整股数量、下一会话、估算金额、费用/滑点、预估资金。估算价不是成交保证。发送后以服务器状态为准，客户端不能乐观显示成交成功。取消提示可能已成交，以服务端最新 revision 判定。

暂停：说明是否撤销当前待执行自动订单，默认撤未执行自动买单并暂停新自动单，已有持仓保留；具体策略可配置但必须在确认页清楚列出。重置：归档旧实验并创建新实验，不覆盖旧净值线。

## 6. 准确度页

默认主窗口 20 交易日；显著显示成熟样本数量、不可执行数量、观察起止与实验类型。买入和卖出两栏；卖出展示避免损失/错失上涨，不和买入胜率相加。净收益曲线与基准同起点，Y 轴清晰，允许表格查看；不能裁图隐藏回撤。

“尚未到期”“缺失终点价格”“样本不足”“历史数据事后回放”“前瞻冻结运行”是不同状态。样本不足时显示数量/原因，不生成一个看似精确的准确率排名。策略比较固定同期间、成本、公司池，否则提示不可直接比较。

单条复盘显示原信号→模拟入口→后续重要事件→目标窗口出口→规则标签→结果与理由。模型可以总结失败原因，但必须区别事后解释与当时可知信息。

## 7. 通用页面状态

每个数据页实现 loading、ready、empty、partial、stale、offline、error、no_permission、withdrawn。只有 loading 显示骨架；失败不让页面永久转圈。partial/stale 保留可读缓存并提示截至时间；离线禁用下单和策略修改，允许读缓存。

网络错误提供重试、错误 ID 和最后同步时间；未授权材料显示来源/元数据允许部分，不伪装为文件不存在。原文链接失效显示固定存档引用（仅权利允许时），不改用无关新闻。账户删除/订阅失效可影响权限，但不能把公开历史绩效改掉。

## 8. 交互、无障碍和本地化

金额采用 locale 格式但保持 USD 标签；中文可显示亿/万，详情给完整美元值；全页面时间可切本地/美东，交易会话 ID 始终可查。所有关键按钮提供无歧义文字；图表有 VoiceOver 摘要和数据表；支持大号字体、减少动态效果、深浅色及横向阅读长表。

通知首次在用户关注公司或开启日报时解释价值再请求，拒绝不阻止使用。敏感通知默认隐藏金额和详细持仓；允许设置静默时段。AI 数据共享需独立清楚的同意流程，不能夹在模糊总条款中。[S08]

视觉方向：信息密度可调、留白适中、固定等宽数字、证据入口始终可见；避免赌场式动效、“稳赚”“立刻买入”倒计时。正式品牌/图标设计在产品验证后开展。
