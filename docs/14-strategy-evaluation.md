# 14 · 建议准确度、绩效与策略迭代

关联 FR-012/013/019。原则：先定义评价问题与时点，再生成建议；保留失败与无成交样本；不把模型自信当预测概率；不把回测结果当实际业绩。

## 1. 三层评价不能混为一个“准确率”

**信息层**：抽取数值、财报口径、事件分类及引用是否正确。数据/解释错误单独计数，不以事后股价上涨证明分析正确。

**预测层**：在预先声明的持有窗口内，评分与相对收益是否相关、买入候选是否更可能跑赢基准、退出建议是否避免后续损失或机会成本。

**交易层**：冻结规则组成的实际模拟账户在成交、现金、成本和风险约束下赚/亏多少。一个信号预测正确可能无法成交，一个高胜率策略也可能被少数大亏抵消。系统标准盘是策略交易层真值，用户手动盘只评其自己的操作。

## 2. 评价窗口与标签

主窗口 H=20 个交易日，辅窗口 1/5/60。入口为建议冻结之后的下一有效计划执行会话开盘；以该会话为第 1 日，H 日出口为第 H 个有效交易会话收盘。窗口按日历索引固定，不因止盈、亏损或停牌选择对策略有利的终点。

预测标签用固定名义金额的影子头寸，与组合订单独立；仍须遵守有效价格、公司行动、成本模型和数据资格。影子头寸无法形成有效入口时标记 `unexecutable`，不计入方向命中但计入覆盖/执行失败分母；没有到出口时 `immature`。临时缺价/退市影响单列，不能静默丢样本。

证券净总回报 `Ri,H` 包含窗口股息及约定双边成本；基准 `Rb,H` 使用同窗口和预先固定成本口径。超额收益 `Xi,H=Ri,H-Rb,H`，不是把它当风险调整 alpha。BUY/ADD 主命中定义 `Xi,H>0`；另报绝对获利 `Ri,H>0`。恰为零单列 tie，不暗记胜利。

SELL/REDUCE 使用**卖出 vs 保留该部分持仓**的反事实：入口按真实可模拟卖价变现为现金，与同一部分持仓继续到出口并卖出的财富比较，统一股息/费率/现金收益假设。报告“避免损失/错失上涨”的美元和百分比差额。另报未来相对基准表现是否较弱。不能将“卖出后上涨但跑输基准”同时包装成避免绝对损失。

HOLD/WATCH 不硬定义为买或卖命中；报告未来收益分布、错过的机会和避免的损失；ABSTAIN 计入覆盖率与缺失原因。动作目的为降低行业集中度时标注 risk_rebalance，不用方向预测准确率评价全部减仓决策。

组合真实退出可以由新信号决定，与固定周期标签分开。禁止事后选择最赚钱的 1/5/20/60 日作为唯一结果。

## 3. 必须展示的指标

| 分类 | 指标及定义/注意 |
|---|---|
| 样本 | 总建议数、可执行数、已成熟数、未成熟/缺价/撤回/失败数 |
| 买入效果 | 绝对胜率、超额命中率、均值/中位收益、亏损尾部、平均盈亏比 |
| 卖出效果 | 反事实避免损失、错失收益、相对弱势命中率；独立于买入统计 |
| 排序 | 同日截面的 Spearman rank IC、分位组净回报和高低分差；截面至少 10 只，否则不报 IC |
| 组合 | 总净收益、累计基准超额、最大回撤、波动、换手、交易成本、现金比例、行业/发行人集中度 |
| 风险调整 | 日超额收益序列的 Sharpe，年化约定 252；rf 必须声明，不足样本/零波动返回 null |
| 概率 | 只对已经校准的明确定义目标报告 Brier、log loss、可靠性曲线及样本量 |
| 运行质量 | 数据覆盖、建议准时率、缺价率、未成交率、拒单率、规则/证据错误率 |

总收益 `NAV_end/NAV_start-1`；有外部注资时使用预定义时间加权方法，初版标准盘不允许追加资金。最大回撤 `max_t(1-NAV_t/max_{s≤t}NAV_s)`。日换手初版定义为当日买卖成交额绝对值之和/前日 NAV，说明是双边口径。profit factor=正已实现盈亏之和/负已实现盈亏绝对值之和；没有亏损样本时不显示无穷大“神策略”。

观察期不足一年时默认不把短期收益外推为宣传性年化收益；实验详情允许显示带明确公式、时间长度与高不确定性标注的估计。回撤和收益必须同起止、同版本。用零风险利率只是基线假设，不等于市场真实无风险利率为零。

## 4. 样本依赖与统计不确定性

同一公司每日重复持有建议、同一财报衍生多条新闻、重叠 20 日收益都不是独立样本。保存 event_cluster、issuer、decision_date 和 label_interval。主事件研究以公司×事件簇首个合格建议为样本；每日截面面板另报，不能混在一个 N 中。

对均值/IC/组合超额使用保留时间与公司相关性的分块/聚类 bootstrap；买入命中区间也报告相关性调整方案，不能只套独立伯努利公式后声称高置信度。所有报告给 N、有效期、样本来源和区间，缺样本显示“尚不能判断”。

概率输出在未校准前为 null。后续以训练外时间验证集建立分数→未来 20 日超额为正的映射，使用明确校准方法与版本；再到独立测试/前瞻样本评估，不在同一数据上拟合并报准确率。Brier=`mean((p-y)^2)`；log loss 对 p 做预声明数值裁剪。

## 5. 防前视、幸存者和模型知识泄漏

每条信息保存 `source_published_at`、`first_seen_at`、`recorded_at`、业务有效期、修订版本。前瞻决策只使用发布且系统实际已见、已完成处理的资料；`available_at` 不能早于其中任何一个必需时点。

历史研究只有真实 PIT 档案或明确模拟延迟模型时才能声称 as-of。今天从 API 下载的重述财报/最新共识不能当历史当时已知数据。只有财报日期而没有准确公开时刻时采用保守可用规则并标注；不能把季度末当披露日。

模型本身可能在训练中见过历史结果。即使提示“仅根据材料”，也不能证明没有泄漏。因此：历史 LLM 研究与真实前瞻模拟分开标记；冻结模型/提示词/输出；禁止外部搜索未来资料；必要时遮蔽名称日期只测试抽取；用确定性规则基线做消融。新模型回跑历史只能叫“事后实验”，不能改写旧时点判断。最有说服力的证据来自建议冻结后真实时间前进的前瞻运行。

宇宙含当时退市/改名/合并证券；原始价格和公司行动均按当时信息处理；财报修订只影响修订公开后的新建议。分析师共识必须有财报之前快照且口径一致，否则不能算超预期。

## 6. 数据划分与走样本外流程

不采用随机 train/test 分割时间序列。候选初始模板：至少 24 个月训练、随后 3 个月验证、随后 3 个月测试，按季度向前滚动；只是研究配置，真实资料不足时不伪造该长度。试点当下 30 公司名单不能直接用于历史全市场效果宣传。

凡特征/标签区间跨边界的样本需 purge；在训练与验证/测试边界设置与最大被优化标签期限相适配的 embargo。若优化 60 日结果，不能只隔离 20 日；是否额外考虑特征可用延迟在 experiment manifest 明确。阈值、组划分、标准化、概率校准、特征选择仅用训练/验证完成。

最终锁定测试集只评价已选候选一次；看过结果再改策略即消耗该测试集，下一轮换新未见时间段或等前瞻结果，不能反复称同一段为“样本外”。保留每次 trial，包括失败/中止，不只登记冠军。对大量搜索需报告试验数量并使用多重检验/选择偏差控制；不得无限搜索直到历史看起来好。

## 7. 初始对照组与消融

至少预注册：现金；同资格池预定周期等权；简单价格动量规则；财务规则但无 LLM 事件；完整 Rules-v1。所有模型同期间、同数据权利、同交易成本、同证券可执行规则。比较额外信息是否带来稳定增益，而非只证明大盘上涨时赚钱。

只比较少量预先登记的候选，初版每轮最多 5 个；后续扩展需要实验预算批准。用户点击、喜欢或跟随某个建议只优化体验，不作为股价预测的训练真值。

## 8. 持续调整而非自动追涨杀跌

每日：新数据/信号/账本/已到期标签更新；检测漂移、缺失、错误和风险。

每周：自动生成归因复盘，分析错在数据、事实理解、规则、估值、市场环境还是执行。AI 可提出待检验假设，不得自动改生产权重、抹掉失败样本或绕过风控。

每月：在已成熟数据上生成至多 5 个登记候选；冻结代码、参数、训练数据 hash、模型/prompt、成本与标签定义；走样本外验证。生产策略保持不变。

候选通过工程/数据门禁后进入 shadow 前瞻盘。初始观察门槛：至少 60 个交易日且至少 100 个去重已成熟事件样本；若采样不足继续观察，这只是最低观察要求，不保证统计充分。60 日窗口的样本必须真成熟。对初期样本少的系统保留实验标记，不能假称已有高准确率。

晋级必须满足：无关键数据/账本/泄漏缺陷；在主评价窗口和约定风险范围内优于预先指定对照的证据；成本压力下没有崩溃；收益不由单一公司/单一事件贡献；独立样本和前瞻结论方向一致；审批人审阅全部候选/失败记录并解释不确定性。证据不充分就不晋级，不能为了“每月升级”放宽门槛。

## 9. 策略版本治理

状态：draft → registered → backtested → validated → shadow → approved → active → retired/rolled_back。

生产晋级在未来生效点切换，新建策略实验 run 或明确分段；原始版本曲线完整保存。标准盘长期连续曲线可显示，但每次版本切换必须标记，同时保留各版本独立对照盘。用户选择跟随最新版需一次明确授权，提前通知规则变化；冻结单版本实验不得静默升级。

回滚触发包括：严重时间泄漏/来源错误、账本不平、权利到期、关键风控失效；先暂停新仓/撤未成交订单，再恢复已批准版本。亏损本身不意味着立刻改参数；统计风险触发阈值预先登记。所有回滚不撤销真实发生的模拟成交，只改变未来执行。

## 10. 用户界面和披露

展示原始建议、当时证据、当时分数、真实冻结时间、模拟入口/出口、费用、基准、后续事件及最终标签。页面永久区分“历史回测”“前瞻模拟”“用户手动实验”；不得只展示盈利案例或只剩存活公司。

任何性能分享卡必须含期间、样本量、费用假设、基准和模拟标记。投资分析工具的方法、局限与假设披露可参考 FINRA 2214；该规则直接适用对象为其会员相关业务，不据此断言本项目天然合规或适用豁免。[S07]
