# 10 · 成本、运行与运营后台

本章只给预算模型和示例假设，不是供应商报价。初版不采购交易级逐笔行情也可以研究财报/日批模拟；但商业展示与历史/PIT/AI权利仍需询价，不能承诺成本很低。

## 1. 成本模型

月成本 = 数据许可固定费 + 数据用量/用户授权费 + LLM输入/输出费 + embedding/检索 + API/worker/数据库/存储/流量 + 通知/监控 + 商店/支付相关费用 + 人工审核/法务/支持。

LLM费用 `sum(input_tokens/1e6*input_price + output_tokens/1e6*output_price)`，逐模型和缓存命中分别记录，不能只按请求数估计。试算：每月1000个事件，每个1万输入+1000输出，合计1000万输入+100万输出token；该数是容量假设，乘采购时真实单价才得预算。问答按活跃用户×问题数×平均token独立估算，不因注册人数直接等比例全公司重算。

数据报价必须询问：30/100/全市场覆盖、历史年数、PIT、共识/电话会、日线/实时、展示用户数、AI推理/训练/衍生评分、导出、缓存/合同终止处理。没有书面答复时预算列TBD，不编造E360/FMP/Massive价格。

## 2. 配额与成本控制

先按材料hash/provider ID去重，再调用模型；同公司同版本报告共享，用户只过滤订阅；增量处理材料变化，不每天重读全部10-K。合并批量数据请求，限制试验并发、历史范围、用户问题长度与证据数量。

预算采用月/日/任务三级：70%提示、90%限制非关键深度任务、100%停止新付费AI任务并保留已核验事实。这是可配置运维规则，不能因此中断已存在的paper账本维护。免费/付费配额后端强制，禁止自动追加采购未授权费用。

## 3. 运行仪表盘

来源：抓取成功、429/403、watermark、延迟、每字段缺失/冲突。AI：调用量/token/成本/延迟、事实支持、拒答、人工复核。策略：冻结时间、coverage、ABSTAIN率、因子分布漂移。交易：计划/成交/拒单、重复事件、现金/持仓不变量。评价：成熟/未成熟/不可执行样本、净值陈旧、主周期区间与试验数量。

运营首页优先处理无法估值、时间泄漏、账本差额和权利到期，不以DAU增长掩盖研究质量。日报同时包含失败任务与未覆盖公司。

## 4. 告警与降级

| 故障 | 自动动作 | 恢复要求 |
|---|---|---|
| 数据缺失/冲突 | 阻止受影响新仓；展示partial | 来源核验、重建新版本，不倒签 |
| AI不可用/预算耗尽 | 事实卡可读，解释延后 | 队列限额恢复，不伪称已分析 |
| 冻结错过截止/开盘 | 取消本轮执行计划 | 下一有效批次，原失败留档 |
| 账本不平/越权 | 暂停执行，保留日志并告警 | 定位、重放、审核后恢复 |
| 行情陈旧/停牌 | 禁止造价成交，风险标记 | 合法有效价格/行动到达后处理 |
| 数据权利到期 | 停相关展示/AI/导出 | 有效合同或许可批准 |
| 新策略异常 | 暂停新仓/撤未成交自动单 | 审批回滚未来版本，不改旧成交 |

关键写入不可用时只读降级；推送失败重试不会重复执行建议。任何告警通知包含run/batch/request ID而非私密全文。

## 5. 运营后台

公司覆盖/映射修订、源材料与解析失败、AI隔离审核、用户纠错、建议撤回追加版本、实验登记/失败记录、晋级审批、paper账本重放差异、预算/许可、用户隐私请求、杀开关。每次敏感操作需要理由、范围、审批角色和审计记录，不提供“修改历史收益”按钮。

后台编辑原始事实只能产生新revision；错误数据删除按权限/法律流程，保留允许的审计元数据。客服不能看全部用户资产样式的模拟持仓，按具体工单最小授权。

## 6. 日/周/月运维

每日检查数据覆盖、冻结准时、成交/估值和成熟标签；每周查错误样例、供应商差异、备份恢复抽检与策略归因；每月核对成本、许可到期、试验登记及候选晋级。策略可以长期不变，不为制造更新而强制调参。

服务目标来自PRD：月核心读取可用性99.5%为设计目标，数据到达/AI/整链延迟分开计，不把供应商未发布算服务器完成。任何SLA对外承诺需实测与合同支持。
