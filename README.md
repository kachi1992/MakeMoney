# MakeMoney

**面向纳斯达克上市公司的 AI 原生财报与重大事件研究 iOS App。**

> 状态：需求与技术设计基线 v1.0，2026-10-02。当前仓库交付的是设计文档与契约示例，不是已经实现或通过测试的 App。MakeMoney 为项目代号，正式品牌、商标和 App Store 名称尚未确定。

## 产品主张

每天自动跟踪公司公开披露，回答：**发生了什么变化、原始证据是什么、与此前披露有什么不同、还有什么不能确定。**

数值由确定性程序计算；模型负责有证据约束的抽取、比较与解释。首版不做交易、自动买卖、收益承诺或个性化买卖建议。

## 首个可交付闭环

```text
选定并版本化的试点公司池
  → SEC / 经授权的财务数据接入
  → 财务期间与数值口径校验
  → 变化检测与事件归并
  → 检索原始证据
  → AI 结构化解释 + 发布校验
  → iOS 今日卡片 / 公司详情 / 证据查看 / 通知
```

MVP 使用 30 家有明确覆盖说明的试点公司验证闭环，随后扩展公司池；产品最终范围是纳斯达克上市公司，而不是将 Nasdaq-100 当成全市场。外国发行人、多股类、退市、改名等必须显式建模。

## 核心边界

- SEC 为公开申报原始来源之一，不是所有新闻、共识预期或电话会的完整来源。
- FMP / Massive 等只作为可替换供应商；个人 API 套餐不自动获得公众展示、再分发或 AI 处理许可。
- 后端持续跟踪，iPhone 负责展示和轻量同步；不依赖 iOS 常驻轮询。
- 所有重要结论带来源、期间、披露时间、数据截至时间及版本；没有证据时明确缺失。
- 所有预算、时延和质量阈值是设计目标或假设，需在实施与试点中验证；不得宣传为已经达到。
