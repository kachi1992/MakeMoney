# MakeMoney

**面向纳斯达克上市公司的 AI 研究、每日股票建议与策略模拟实验 iOS App。**

> 需求与技术设计基线 **v1.1 · 2026-10-02**。本仓库当前交付设计文档、接口契约及合成样例，**不代表 App、后台、策略或测试已经实现**。MakeMoney 是项目代号，不是收益承诺。

## 产品闭环

```text
财报 / 业绩 / 重大事件 / 经授权行情
  → 标准化数据 + 可追溯证据 + 公司长期记忆
  → 财务变化检测 + AI 解释
  → 每日评分与买入 / 增持 / 持有 / 减持 / 卖出 / 观望建议
  → 不可回写的建议账本
  → 系统基准模拟盘 + 用户独立模拟盘
  → 到期标签 / 成本后收益 / 超额收益 / 风险 / 概率校准
  → 候选策略 → 样本外验证 → 前瞻模拟 → 人工批准新版本
```

每天更新信息和建议，**不等于每天必须交易**。不满足证据、质量或风险条件时允许观望。首版不连接真实券商、不接触真实资金、不自动实盘下单；模拟结果不能宣称为真实业绩。公开提供证券建议的许可与上架评估是独立发布门禁，不能靠“仅供参考”自动豁免。

## 实施基线

- iPhone 优先、中文主界面、英文原文保留；iOS 最低部署目标暂定 18，具体 Xcode/SDK 在 P0 锁定并验证。
- 先用 30 家版本化试点公司验证覆盖和前瞻运行，再扩到 100 家及全纳斯达克；Nasdaq-100 不等于全部纳斯达克上市公司。
- 后端持续采集和计算；iOS 不承担常驻轮询、定时交易或策略训练。
- 数值、仓位、成交及评分计算由确定性程序执行；LLM 只处理有证据约束的抽取、比较和解释。
- 策略参数是待检验实验假设，不是已经找到的赚钱策略。排序分不是上涨概率。
- 模拟盘默认美元、仅做多、无杠杆；卖出只减少已有持仓。系统标准盘和用户操作盘严格隔离。
- 所有正式建议在执行前冻结；数据更正、模型更换和策略升级均追加版本，不能事后修改旧建议美化收益。

## 最先阅读

产品需求 → 每日建议 → 模拟交易 → 评估迭代 → 数据模型 → API → 路线图。首个验收闭环必须包含“信息更新—可解释建议—模拟成交—复盘”，不是仅完成新闻摘要。

没有商业展示 / AI 使用权限时，保留相同接口，用合成数据或允许的内部数据开发。不要向仓库提交 API Key、真实用户资料、商业数据全文、证书或实盘凭证。
